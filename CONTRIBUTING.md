# Contributing

This is a **fixed-scope portfolio demo**, not an open product under active
feature development. It is not seeking new contributions, feature PRs, or
issue-driven roadmap work.

If you found a clear bug in the demo runtime or examples (broken tests, typo
that blocks `pytest`, etc.), a small fix PR is welcome. Anything larger
belongs in the commercial GraphForge product, which is private and separate
from this repository.

See the [README](README.md) for scope and license notes.
